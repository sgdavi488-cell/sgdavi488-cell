## Projetos em destaque

### Controle de Estoque

Projeto para organizar produtos de supermercado e acompanhar o estoque.

- [Abrir aplicação](https://sgdavi488-cell.github.io/controle-estoque/)
- [Repositório](https://github.com/sgdavi488-cell/controle-estoque)

### Finance Control

Painel simples para registrar entradas e despesas e acompanhar o saldo mensal. Pode ser usado para finanças pessoais ou para um controle básico de pequenos negócios.

- [Abrir aplicação](https://sgdavi488-cell.github.io/finance-control/)
- [Repositório](https://github.com/sgdavi488-cell/finance-control)

### Cardápio Digital — Maison

Projeto de cardápio para restaurante que comecei durante um curso de programação e depois decidi refazer. Tem categorias, busca, filtros e carrinho interativo, com os detalhes do pedido preparados para envio pelo WhatsApp.

- [Abrir cardápio](https://sgdavi488-cell.github.io/cardapio-digital/)
- [Repositório](https://github.com/sgdavi488-cell/cardapio-digital)

### Brasil Rush 3D

Projeto de jogo no estilo endless runner, baseado na ideia geral de jogos como Subway Surfers. A proposta é desenvolver um jogo de corrida em 3D com tema brasileiro.

- [Abrir projeto](https://sgdavi488-cell.github.io/subway/)
- [Repositório](https://github.com/sgdavi488-cell/subway)
